# 外网穿透 · 国内备用隧道（双模式对接手册）

> 适用：cloudflared（trycloudflare.com）在手机所在网络不可达/不稳定时，切换国内可达的隧道。
> 主用 cloudflared 默认无需任何操作仍在运行。本手册用于**备用的第二条路**。

## 对接原理（watchdog 双模式）

常驻进程 `E:\DSH Zone\.tools\tunnel-watchdog.ps1`（Task Scheduler `DSH Mini Tunnel Watchdog` + 每 5 分钟任务托管）支持两种模式：

| 模式 | 触发条件 | 谁管隧道进程 | 谁同步 publicUrl |
|---|---|---|---|
| cloudflared 模式（默认） | `manual-url.txt` 不存在或为空 | watchdog 自起/自愈 cloudflared | watchdog 自动 |
| 手动模式（备用隧道） | `manual-url.txt` 里填了 https 地址 | **你自己**运行国内隧道客户端 | watchdog 仍自动同步到 dsh-mini 设置 |

**切换 = 编辑一个文件**：

- 写入手动地址 → watchdog 停止管理 cloudflared，把该地址同步为 dsh-mini 的 publicUrl（桌面设置卡 / 二维码 / `external.url` 跟着变）。
- 清空 / 删除该文件 → 自动回落到 cloudflared 真地址（默认模式）。

配置文件
- `E:\DSH Zone\.tools\manual-url.txt` —— 手动模式地址（watchdog 每 12s 读一次）
- `E:\DSH Zone\.tools\tunnel-url.txt` —— 当前生效公网地址（供你随时查看）
- 模板：`E:\DSH Zone\.tools\manual-url.txt.example`

支持内容：`https://xxx` 或 `http://xxx`（不写协议前缀会自动补上 https://）。**必须指向 `127.0.0.1:46322`**（dsh-mini 网关端口），不能指向 DSH 主端口（红线 I1）。

## 方案 A：樱花frp（natfrp.com）—— 国内免费、可自定义子域名

1. 注册账号：<https://www.natfrp.com>（国内直达，手机/电脑都能开）。
2. 控制面板 → 创建隧道：
   - 类型：**HTTP**
   - 本地地址：`127.0.0.1`
   - 本地端口：`46322`
   - 远程域名：起一个子域名（免费版给你一个固定的 `*.sakurafrp.xyz` 之类的地址，重启不变）
   - 若有「HTTPS/证书」选项：开启（免费版通常可用）
3. 下载 **SakuraFrp Launcher** 登录并启动隧道；或按面板给出的 frpc 配置命令行启动。
4. 把公网地址（形如 `https://你的子域名.xxx`）填入：
   `E:\DSH Zone\.tools\manual-url.txt`
5. 等 ≤15s，桌面「手机桥」设置卡 / `tunnel-url.txt` 即显示新地址。

注意：樱花免费版限速、需保持 Launcher 运行；断线会自动重连（Launcher 负责），地址不变。

---

## 方案 B：cpolar —— 零门槛 CLI，一条命令起隧道

1. 注册：<https://www.cpolar.com> → 控制面板拿到 authtoken。
2. 下载客户端（Windows 解压即用）→ 命令行：
   ```
   cpolar authtoken <你的token>
   cpolar http 46322
   ```
3. 启动后终端/面板会给出公网地址，形如 `https://<随机>.cpolar.top`（免费版地址重启会变）。
4. 把最新公网地址填入 `E:\DSH Zone\.tools\manual-url.txt`；地址变了就再更新一次（watchdog 会自动同步，手机只认最新）。

注意：cpolar 免费版子域名随机且重启变化 → 每次重启后看一次面板把新地址贴进 manual-url.txt 即可；可把 cpolar 设为开机自启保持运行。

## 通用注意事项

- **必须 HTTPS 优先**：手机走公网尽量用 https 地址（明文 http 可能被运营商注入广告/劫持）。dsh-mini 的 `publicUrl` 两种协议都接受。
- **必须支持 WebSocket**：手机 GUI 的 `ws://` 事件流依赖隧道转发 Upgrade。cloudflared / 樱花 / cpolar 均支持；若用其他自备隧道，先确认能透传 WS。
- **上传上限**：publicMode 下自动钳到 50MB（可再在设置里调低）。
- **安全**：publicMode 下未带 token 一律 403；管理端点仍仅本机。备用隧道同样只暴露网关端口，别把 7618（DSH 主端口）暴露出去。

## 回切主用（cloudflared）

把 `manual-url.txt` 清空或删除 → ≤30s 内 watchdog 自动重新拉起 cloudflared 并同步回它的地址。cloudflared 主通道与备用通道可随时来回切。
